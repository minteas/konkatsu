FAQ

Q
かなり人見知りですが、楽しめますか？
+
このパーティーは人見知りさんのために設計されています。ゲームが自動的に会話のきっかけを作るので、「何か話さなきゃ」と焦らなくて大丈夫。むしろ人見知りの方のほうが「思ったより楽しかった」とおっしゃることが多いです。
Q
婚活パーティー自体が初めてで不安です
+
初参加の方が毎回半数以上を占めます。受付時にスタッフが当日の流れとゲームのルールをすべて丁寧にご説明するので、事前に何も準備しなくても大丈夫です。
Q
運動が苦手でも大丈夫ですか？
+
運動や体力は一切不要です。コミュニケーションや頭を使う協力系ミッションが中心です。苦手な方がむしろ「助けてもらう側」になることで、距離が縮まることも多いです。
Q
一人での参加ですが大丈夫ですか？
+
参加者のほぼ全員がおひとりでのご参加です。全員が同じ立場ですのでご安心ください。スタッフが丁寧にフォローします。
Q
キャンセルはできますか？
+
開催3日前までのキャンセルは全額返金いたします。2日前〜前日は50%、当日キャンセルは返金不可となります。
